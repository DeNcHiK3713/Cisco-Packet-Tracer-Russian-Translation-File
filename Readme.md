# Cisco Packet Tracer Russian Translation File.
Полный ИИ перевод для версии Cisco Packet Tracer 9.0.0.

## Скачать:
[скачать скомпилированный файл](https://github.com/DeNcHiK3713/Cisco-Packet-Tracer-Russian-Translation-File/releases/latest/download/russian.ptl)

## Установка:
1. Скопируйте файл "russian.ptl" в папку Cisco Packet Tracer 9.0.0\languages
2. В интерфейсе программы Options -> Preferences выберете "russian.ptl" и нажмите Change language.
3. Перезапустите программу!
